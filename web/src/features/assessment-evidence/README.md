# Assessment evidence

Maqueta local de WEBUI-003 para inspeccionar una evaluación, distinguir una propuesta IA de la decisión docente y demostrar acciones separadas de revisión, aprobación y publicación.

| Archivo | Propósito |
|---|---|
| [`data.ts`](data.ts) | Fixtures deterministas de evaluaciones, lifecycle, evidencia, permisos e historial. |
| [`AssessmentEvidencePage.tsx`](AssessmentEvidencePage.tsx) | Composición client-side de la ruta de detalle y acciones locales. |
| [`AssessmentEvidencePage.module.css`](AssessmentEvidencePage.module.css) | Layout responsive, estados y accesibilidad visual de la feature. |

La superficie no llama API, Firebase ni IA real, y no persiste decisiones.
