# Diseño WebUI

Documentación de diseño y alcance de las maquetas docentes de GradeOps Web.

| Documento | Alcance |
|---|---|
| [WEBUI-002 — Bandeja de Operaciones](webui-002-operations-inbox.md) | Maqueta pseudofuncional local para preparar, revisar, confirmar y aprobar trabajo docente. |
| [WEBUI-003 — Detalle de evaluación y evidencia IA](webui-003-assessment-evidence.md) | Diseño de una vista local para inspeccionar evidencia, incertidumbre y decisiones humanas sobre una evaluación. |
| [WEBUI-003 — Mapa de destinos de Operaciones](webui-003-operations-action-destination-map.md) | Significado, destino y estado de implementación de cada acción de la Bandeja de Operaciones. |
| [WEBUI-004 — Flujo docente de autoría de evaluaciones](webui-004-assessment-authoring-flow.md) | Flujo completo desde el estado sin datos hasta crear, reutilizar, asignar y publicar evaluaciones. |
| [WEBUI-004 — Rúbricas reutilizables](webui-004-rubric-authoring.md) | Diseño de la Work Unit 4: criterios, niveles, pesos, cobertura, versionado y revisión humana. |

Estas especificaciones describen UIs locales con datos deterministas. No constituyen contratos API ni implican que las entidades o mutaciones descritas estén implementadas en backend.
